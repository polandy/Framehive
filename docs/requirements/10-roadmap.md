# 10. Roadmap

Part of the [requirements](README.md).

| Phase | Content |
|---|---|
| 0 · Prototypes | Slint grid with 200,000 thumbnails, decoding X-T2/X-T5 RAF (all compression modes), Canon 7D CR2 and the DNG reference set with LibRaw, Slint test APIs, writing XMP + round trip with digiKam/darktable, gphoto2 on Linux and macOS |
| 1 · MVP | Import module complete including background jobs and CLI; reference cameras and formats: Fujifilm X-T2/X-T5, Canon EOS 7D, DNG (2.8); library: folders/date, grid, RAW + JPEG grouping (5.3), Nextcloud sync folder as root and import target (6.4), loupe, comparison, ratings, labels, tags, filter, search, albums, XMP; multiple roots including offline and NAS |
| 2 · v1 | digiKam migration, multiple machines with merge, smart collections, stacks, duplicates & similarity, export; Immich integration: faces/people, albums, tags, places, previews, content search (6.5) |
| 3 · soon after v1 | Map & geotagging; local face recognition and content search for photos outside Immich |
| 4 · later | Editor or deeper darktable integration; evaluate Windows |
