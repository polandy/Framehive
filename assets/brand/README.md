# Brand

The name joins *frame* and *hive*. A photo library is a hive of framed pictures.

## Logo

Six viewfinder corners are arranged as a hexagon around one honey-coloured honeycomb
cell. The corners are the frame, the cell is the hive, and the cell sits where a camera
puts its focus point. Next to it is the wordmark "framehive" in lower case.

| File | Use |
|---|---|
| `logo-mark.svg` | Mark only, for light backgrounds |
| `logo-mark-dark.svg` | Mark only, for dark backgrounds |
| `logo-horizontal-light.svg` | Mark and wordmark, for light backgrounds |
| `logo-horizontal-dark.svg` | Mark and wordmark, for dark backgrounds |
| `app-icon.svg` | App icon, 512 × 512, rounded tile |
| `app-icon-maskable.svg` | App icon, full bleed, with the mark inside the safe zone |
| `favicon.svg` | Heavier cut for 16–32 px. It follows the browser's light or dark scheme |

The SVG files are generated by `generate.py`. Edit the script, not the outputs:

```sh
uv run --no-project --with fonttools==4.66.1 --with uharfbuzz==0.56.3 \
    assets/brand/generate.py
```

PNG and ICNS icons are build outputs and never committed (ADR 0017).

## Colours

| Name | Value | Use |
|---|---|---|
| Honey | `#F4A51C` | The cell. It is the only accent, so keep it small |
| Ink | `#17150F` | Frame and text on light, and the app icon tile |
| Paper | `#FBF8F1` | Frame and text on dark |

The honey cell stays honey on every background. Never recolour or rotate the mark, never
outline the cell, and keep a clear space of at least the cell's width around the mark.

## Type

The wordmark is Sora SemiBold with −0.03 em tracking. The glyphs are outlined to paths,
so the logo renders without the font. Sora is licensed under the SIL Open Font License
1.1. The script fetches it from a pinned google/fonts commit and checks its SHA-256.
